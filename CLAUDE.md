# Reglas de este repositorio (mi-contexto)

Este repositorio guarda el contexto personal y de negocio de Roger Soto para la Academia Catalizadora. No es un proyecto de código — no crear carpetas de source code aquí.

## Contenido de este repo
- `quien-soy.md`, `que-hago.md`, `que-he-hecho.md`, `como-me-gusta-trabajar.md`, `en-que-estoy.md` — los 5 archivos de contexto personal de la Sesión 1.
- `prompts/` — personas (`asistente.md`, `analista.md`, `redactor.md`) y ejemplos de voz (`ejemplos-few-shot.md`) de la Sesión 2.
- `.github/workflows/briefing-diario.yml` — automatización de la Sesión 3 (no es código de negocio, es el agente autónomo que corre solo cada día). `briefing.md` es su salida.

## Cómo mantenerlo
- Actualizar `en-que-estoy.md` cuando cambien las prioridades del mes.
- Actualizar los 5 archivos de contexto cuando cambie algo real del negocio (nuevo producto, nuevo servicio, cambio de prioridades).
- Cada cambio en este repo se sube a GitHub (`git add`, `commit`, `push`) para que cualquier sesión de Claude Code, en cualquier computadora, pueda leerlo.
